How to Set Up Google Email and Calendar

A plain-English guide to connecting your Gmail and Google Calendar to the AI Email Agent.

What's in this guide

  1. What you need before you start
  2. Create a Google Cloud project
  3. Turn on Gmail and Calendar
  4. Create your login credentials
  5. Download and name the credentials file
  6. Install Python on your computer
  7. Install the agent software
  8. Sign in to Google (one-time step)
  9. Run the agent
  10. Quick reference commands
1

What You Need Before You Start

  • 📧 A Gmail account (e.g. brandon.usgovtservices@gmail.com)
  • 🔑 An Anthropic API key — get one free at console.anthropic.com
  • 💻 A Mac or Windows computer with internet access
  • 🐍 Python installed (we'll cover this in Step 6)
2

Create a Google Cloud Project

Think of this as creating a "container" in Google where your app will live.

  1. Open your browser and go to console.cloud.google.com. Sign in with your Google account.
  2. At the very top of the page, click the project dropdown (it might say "My First Project" or "Select a project").
  3. Click New Project in the top-right corner of the popup.
  4. In the Project name box, type: Email Agent — then click Create.
  5. Wait a few seconds, then click the project dropdown again and select Email Agent to make sure it's selected.
✓ You'll know you're done when you see "Email Agent" shown at the top of the page.
3

Turn On Gmail and Calendar

You need to "enable" both services so your agent is allowed to use them.

  1. In the left sidebar, click APIs & Services, then click Library.
  2. In the search box, type Gmail API. Click on it in the results, then click the blue Enable button.
  3. Go back to the Library (click the back arrow or click Library in the sidebar again).
  4. Search for Google Calendar API. Click it, then click Enable.
✓ You'll know you're done when both APIs show a green "Disable" button (that means they're already on).
4

Create Your Login Credentials

This is what lets your agent log into Google on your behalf.

  1. In the left sidebar, click APIs & Services → Credentials.
  2. Click + Create Credentials at the top, then choose OAuth client ID.
  3. If a yellow banner says "Configure Consent Screen", click that button first:
    • Choose External → click Create
    • Fill in App name: Email Agent
    • Fill in User support email: your Gmail address
    • Scroll to the bottom, fill in Developer contact email: your Gmail address
    • Click Save and Continue three times until you reach the Dashboard
    • On the Dashboard, click + Add Users and add your Gmail address
  4. Back on the Credentials page, click + Create Credentials → OAuth client ID again.
  5. For Application type, choose Desktop app.
  6. For Name, type: Email Agent — then click Create.
✓ You'll know you're done when a popup appears showing "Your client ID" and "Your client secret".
5

Download and Name the Credentials File

  1. In the popup that appeared, click Download JSON. A file will download to your computer.
  2. Find the downloaded file. It will have a long name like client_secret_850853...json.
  3. Rename it to exactly: credentials.json (all lowercase, no spaces).
  4. Move it into your Email-Agent project folder.
⚠️ Important: Never share this file or upload it to GitHub. It gives access to your Google account.
6

Install Python on Your Computer

Python is the programming language the agent runs on. You only do this once.

🍎 Mac

  1. Open Terminal (press Cmd+Space, type Terminal, hit Enter)
  2. Type this and press Enter:
    python3 --version
    If you see a version number, Python is already installed. Skip to Step 7.
  3. If not installed, go to python.org/downloads and click the big yellow Download button. Open the installer and follow the steps.

🪟 Windows

  1. Press Win+R, type cmd, press Enter
  2. Type this and press Enter:
    python --version
    If you see a version number, Python is already installed. Skip to Step 7.
  3. If not installed, go to python.org/downloads, download the installer, run it, and check the box that says "Add Python to PATH" before clicking Install.
7

Install the Agent Software

This downloads all the pieces the agent needs to run.

🍎 Mac — in Terminal

# Navigate to the project folder
cd ~/Email-Agent

# Create your .env file
echo "ANTHROPIC_API_KEY=your-key-here" > .env
echo "TIMEZONE=America/New_York" >> .env

# Install everything
pip3 install -r requirements.txt

🪟 Windows — in Command Prompt

:: Navigate to the project folder
cd %USERPROFILE%\Email-Agent

:: Create your .env file
echo ANTHROPIC_API_KEY=your-key-here > .env
echo TIMEZONE=America/New_York >> .env

:: Install everything
pip install -r requirements.txt
Replace your-key-here with your actual Anthropic API key from console.anthropic.com.
8

Sign In to Google (One-Time Step)

The first time you run the agent, a browser window will open asking you to sign in. You only do this once.

  1. In Terminal (Mac) or Command Prompt (Windows), run:
    python agent.py --dry-run
  2. A browser window will automatically open. Sign in with brandon.usgovtservices@gmail.com.
  3. Google will ask: "Email Agent wants access to your Gmail and Calendar" — click Allow.
  4. The browser will show a message saying authentication is complete. Go back to Terminal/Command Prompt.
  5. The agent will run a test scan of your inbox. You'll see output like:
    Email Agent ready [dry-run].
    Connected to Google services.
    Found X unread email(s).
✓ You'll know you're done when you see "Connected to Google services." — a file called token.json is now saved in your folder. You won't need to sign in again.
9

Run the Agent

You're ready to go. Here's how to use it.

  1. Process your inbox now — reads unread emails and creates Gmail drafts:
    python agent.py
  2. Check your Gmail Drafts folder — any emails that needed a reply will have a draft waiting for you to review and send.
  3. Check Google Calendar — any meeting requests will have been added automatically.
Remember: The agent never sends emails on its own. It only creates drafts. You are always in control of what gets sent.
10

Quick Reference Commands

Open Terminal (Mac) or Command Prompt (Windows), navigate to your Email-Agent folder, then run any of these:

What you want to do Command
Process your inbox right now python agent.py
Process only 5 emails at a time python agent.py --limit 5
Test run — no drafts created python agent.py --dry-run
Run automatically every 15 minutes python agent.py --watch
Run automatically every 5 minutes python agent.py --watch --interval 5
✓ All done! Your AI email agent is connected to Gmail and Google Calendar. New emails will be processed automatically, drafts will appear in your Gmail Drafts folder, and meeting requests will be added to your calendar.
