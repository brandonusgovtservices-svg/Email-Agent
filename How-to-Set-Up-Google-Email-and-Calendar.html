How to Set Up Google Email and Calendar

A plain-English guide to connecting your Gmail and Google Calendar to the AI Email Agent — written for Mac and Windows.

1

What You Need Before You Start

  • 📧 A Gmail account — this is the inbox the agent will manage
  • 🔑 An Anthropic API key with credits — sign up at console.anthropic.com, then go to Plans & Billing to add a payment method (a small amount like $5 goes a long way)
  • 💻 A Mac or Windows computer with internet access
  • 🐍 Python 3.8 or newer — we'll cover installation in Step 6
  • 📦 Git — download free from git-scm.com if you don't have it
About the API key: The Anthropic API is not free — it charges per email processed. Typical cost is less than $0.01 per email. Add at least $5 in credits to get started.
2

Create a Google Cloud Project

Think of this as creating a "container" in Google where your app lives. This is free.

  1. Open your browser and go to console.cloud.google.com. Sign in with your Gmail account.
  2. At the very top of the page, click the project dropdown (it may say "My First Project" or "Select a project").
  3. Click New Project in the top-right corner of the popup window.
  4. In the Project name box, type: Email Agent — then click Create.
  5. Wait a few seconds for it to be created, then click the project dropdown again and select Email Agent to make sure it's the active project.
✓ You'll know you're done when you see "Email Agent" shown in the project dropdown at the top of the page.
3

Turn On Gmail and Calendar

You need to "enable" both APIs so your agent is allowed to read your email and calendar.

  1. In the left sidebar, click APIs & Services, then click Library.
  2. In the search bar at the top, type Gmail API. Click on the result that says "Gmail API", then click the blue Enable button.
  3. Click the back arrow in your browser, or click Library in the left sidebar to go back.
  4. Search for Google Calendar API. Click on it, then click Enable.
✓ You'll know you're done when both API pages show a Manage or Disable button — that means they are already turned on.
4

Create Your Login Credentials

This is what allows your agent to log into Gmail and Calendar on your behalf.

  1. In the left sidebar, click APIs & Services, then click Credentials.
  2. Click the blue + Create Credentials button at the top, then choose OAuth client ID.
  3. If a yellow banner appears saying "To create an OAuth client ID, you must first configure your consent screen", click Configure Consent Screen:
    • Choose External → click Create
    • App name: type Email Agent
    • User support email: select your Gmail address from the dropdown
    • Scroll all the way to the bottom — Developer contact information: type your Gmail address
    • Click Save and Continue
    • On the Scopes page, click Save and Continue (no changes needed)
    • On the Test Users page, click + Add Users, type your Gmail address, click Add, then click Save and Continue
    • Click Back to Dashboard
  4. Now go back to Credentials in the sidebar, click + Create Credentials again, and choose OAuth client ID.
  5. For Application type, choose Desktop app from the dropdown.
  6. For Name, type: Email Agent — then click Create.
✓ You'll know you're done when a popup appears showing "OAuth client created" with a client ID and client secret listed.
5

Download and Name the Credentials File

  1. In the popup that appeared after creating the client, click Download JSON. A file will be saved to your Downloads folder.
  2. If you closed the popup, go to Credentials in the sidebar. Find your client under "OAuth 2.0 Client IDs" and click the download icon (⬇) on the far right.
  3. Find the downloaded file — it will have a long name like client_secret_850853....json.
  4. Rename it to exactly: credentials.json (all lowercase, no spaces).
  5. Leave it in your Downloads folder for now — we'll move it in the next step.
🔒 Security warning: Never share this file with anyone, never email it, and never upload it to GitHub. It gives full access to your Gmail and Calendar.
6

Install Python on Your Computer

Python is the programming language the agent runs on. You only install it once.

🍎 Mac

  1. Open Terminal: press Cmd + Space, type Terminal, press Enter.
  2. Type this and press Enter:
    python3 --version
    If you see something like Python 3.11.4, you're done — skip to Step 7.
  3. If you see an error, go to python.org/downloads, click the big yellow Download Python button, open the installer, and follow the steps.

🪟 Windows

  1. Open Command Prompt: press Win + R, type cmd, press Enter.
  2. Type this and press Enter:
    python --version
    If you see a version number, you're done — skip to Step 7.
  3. If not installed, go to python.org/downloads, download the installer, run it, and — very important — check the box that says "Add Python to PATH" before clicking Install Now.
7

Download the Agent and Set Up Your API Key

This downloads the agent code and sets up your secret keys.

🍎 Mac — in Terminal

# Download the agent code
git clone https://github.com/brandonusgovtservices-svg/email-agent Email-Agent
cd Email-Agent

# Move your credentials file here
mv ~/Downloads/credentials.json .

# Install required packages
pip3 install -r requirements.txt

🪟 Windows — in Command Prompt

:: Download the agent code
git clone https://github.com/brandonusgovtservices-svg/email-agent Email-Agent
cd Email-Agent

:: Move your credentials file here
move %USERPROFILE%\Downloads\credentials.json .

:: Install required packages
pip install -r requirements.txt

Create your .env file (stores your API key)

Open a plain text editor (Notepad on Windows, TextEdit on Mac). Create a new file with these two lines, then save it as .env inside the Email-Agent folder:

ANTHROPIC_API_KEY=your-actual-key-here
TIMEZONE=America/New_York
Replace your-actual-key-here with your real Anthropic API key from console.anthropic.com. The key starts with sk-ant-...
Mac TextEdit tip: Before saving, go to Format → Make Plain Text, then save the file as .env (with no .txt extension).
8

Sign In to Google (One-Time Step)

The very first time you run the agent, a browser window opens so you can approve access. This only happens once — after that, it logs in automatically.

  1. In Terminal (Mac) or Command Prompt (Windows), make sure you're in the Email-Agent folder, then run:
    Mac:
    python3 agent.py --dry-run
    Windows:
    python agent.py --dry-run
  2. A browser tab will open automatically showing a Google sign-in page. Sign in with your Gmail account.
  3. Google will show a warning: "Google hasn't verified this app." This is normal for personal projects. Click Continue (or Advanced → Go to Email Agent).
  4. On the next screen, check both boxes — Gmail and Calendar — then click Continue.
  5. The browser will say "The authentication flow has completed." Go back to Terminal/Command Prompt.
  6. The agent will scan your inbox. You'll see:
    Email Agent ready [dry-run].
    Connected to Google services.
    Found X unread email(s).
✓ You'll know you're done when you see "Connected to Google services." A file called token.json is now saved in your Email-Agent folder. You won't need to sign in again unless you delete it.
Note: The --dry-run flag means the agent reads your emails but does NOT create any drafts or calendar events. It's a safe test to confirm everything is connected.
9

Run the Agent

Once the dry-run works, you're ready to go live.

  1. Run it for real — processes your inbox and creates Gmail drafts:
    Mac:
    python3 agent.py
    Windows:
    python agent.py
  2. Open Gmail in your browser. Click Drafts in the left sidebar. Any emails that needed a reply will have a draft ready for you to review.
  3. Open Google Calendar. Any meeting requests from your emails will have been added automatically.
  4. Read each draft, make any edits you want, then hit Send when you're happy. The agent never sends on its own.
Remember: The agent only creates drafts — it never sends emails. You always review and send manually.
10

What to Expect

Here's what the agent does for different types of emails:

📅 Meeting requests
Adds a calendar event, drafts a casual confirmation reply to the sender, and labels the email Scheduling in Gmail.
🚨 Urgent emails
Labels the email Urgent in Gmail and drafts a prompt reply. Urgent = hard deadlines, ASAP language, escalating clients.
💬 Regular emails
Drafts a casual, direct reply signed with your full name, title, and contact info.
🤖 Automated emails
Skips drafting for newsletters, receipts, notifications, and no-reply addresses. Explains why in the terminal output.
Where to find results: Drafted replies appear in your Gmail Drafts folder. New meetings appear on Google Calendar. Labels appear on the email in your Gmail inbox.

Troubleshooting

❌ "credentials.json not found"
You haven't moved the credentials.json file into the Email-Agent folder yet, or it still has its original long name. Rename it to exactly credentials.json and place it in the Email-Agent folder.
❌ "credit balance is too low" or "ANTHROPIC_API_KEY" error
Either your .env file doesn't have the key, or your Anthropic account has no credits. Go to console.anthropic.com → Plans & Billing and add a payment method. Also double-check your .env file has the line: ANTHROPIC_API_KEY=sk-ant-...
❌ "python: command not found" (Mac)
On Mac, use python3 instead of python. All the commands in this guide for Mac use python3.
❌ Browser didn't open during sign-in
Copy the URL that prints in the terminal and paste it manually into your browser. Sign in, approve access, then copy the URL from your browser's address bar (it starts with http://localhost?code=...) and paste it back into the terminal.
❌ Google says "This app isn't verified"
This is normal for personal apps. Click Advanced at the bottom of the warning, then click Go to Email Agent (unsafe). This is your own app — it's safe.
❌ "No module named" error
The required packages haven't been installed. Make sure you're inside the Email-Agent folder and run: pip3 install -r requirements.txt (Mac) or pip install -r requirements.txt (Windows).
❌ token.json error / need to sign in again
Delete the token.json file from your Email-Agent folder, then run python3 agent.py --dry-run again to go through the sign-in flow one more time.

Run Automatically on Startup (Always-On)

This makes the agent start automatically every time you log into your Mac and run silently in the background — no terminal window needed, checks every 15 minutes around the clock.

Requirements: Your Mac needs to be turned on and logged in. It doesn't need to be awake — the agent catches up automatically when the Mac wakes from sleep.

One-time setup — run these 3 commands in Terminal:

# 1. Go to your project folder
cd ~/Email-Agent

# 2. Run the setup script (only need to do this once)
bash setup_autostart.sh

# 3. Confirm it's running
launchctl list | grep emailagent
✓ You'll know it's working when the last command shows a line with com.usgovtservices.emailagent. The agent is now running and will restart itself automatically after every login or crash.

Managing the background service:

What you want to do Command
Watch the live log tail -f ~/Library/Logs/email-agent.log
Check if it's running launchctl list | grep emailagent
Stop the agent launchctl unload ~/Library/LaunchAgents/com.usgovtservices.emailagent.plist
Start it again launchctl load ~/Library/LaunchAgents/com.usgovtservices.emailagent.plist
Uninstall completely bash ~/Email-Agent/uninstall_autostart.sh
